# Sales Data Analysis

A beginner-level data analytics project using Python, Pandas, and Matplotlib.

## Features
- Reads sales records from a CSV file
- Calculates revenue for each row
- Summarizes total revenue and units sold
- Compares revenue by product and month
- Creates a monthly revenue bar chart

## Files
- `sales_data.csv` — illustrative sample dataset
- `analysis.py` — analysis script
- `requirements.txt` — required Python libraries

## Run locally
Install Python, then run:

```bash
pip install -r requirements.txt
python analysis.py
```

The sample data is illustrative, not real company sales.
